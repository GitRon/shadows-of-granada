RECONQUISTA

Kooperatives Kartenspiel für 2–4 Spieler · Regelwerk V1

Ziel

Sieg: Alle fünf muslimischen Regionskrisen lösen und damit die Reconquista abschließen. Granada fällt zuletzt – mit zwei gestapelten Krisen.
Niederlage: 6 ungelöste Krisen gleichzeitig auf dem Tableau – oder eine Runde endet in der kein einziger Spieler einen Token auf eine Krise legen konnte.

Komponenten

  • 1 gemeinsames Tableau (6 Regionen von Nord nach Süd)
  • 24 Aktionskarten (gemeinsames Deck, 4 pro Symbol)
  • 12 dynamische Krisenkarten
  • 6 fixe Regionskrisen (eine pro muslimische Region, Granada zwei)
  • 4 Königreich-Tableaus (je 3 Slots mit aufgedruckter Startverstärkung)
  • 72 Symboltokens (12 pro Symbol) + 12 Eskalationsmarker
  • 1 W6

Symbole

⚔️Militär – Schlachten, Belagerungen, Verteidigung
✝️Kirche – Legitimität, Moral, päpstliche Unterstützung
👑Diplomatie – Allianzen, Heiratspolitik, Verhandlungen
💰Handel – Finanzen, Tribute, Söldner
🏰Burgen – Grenzsicherung, Befestigung, Rückzugsort
🌾Besiedlung – Bevölkerung, Landwirtschaft, Stabilität

Karten

Jede Aktionskarte hat drei Bereiche:

  • Aktion (oben): Was passiert wenn die Karte oben auf einem Slot liegt und gespielt wird.
  • Fixbonus: Ein fixer Symbolbonus der immer dazukommt wenn die Karte oben liegt – unabhängig vom Stapel darunter.
  • Verstärkung (unten): Symbole die die Karte beisteuert wenn sie unter einer anderen Karte liegt.
Stärke eines Stapels: Summe aller passenden Symbole im gesamten Stapel + Fixbonus der obersten Karte + aufgedruckte Startverstärkung des Tableaus.

Wichtige Grundregeln

Karten werden nicht verbraucht

Eine gespielte Karte bleibt immer auf dem Slot liegen. Karten verschwinden nur durch Krisenstrafen die explizit das Abwerfen verlangen.

Stapelregeln

  • Neue Karten dürfen oben oder unten auf einen Slot gelegt werden – die Entscheidung ist endgültig.
  • Einmal gelegte Karten können nicht mehr verschoben oder umgeschichtet werden.
  • Es gibt keine Begrenzung wie viele Karten auf einem Slot liegen dürfen.
  • Die oberste Karte bestimmt immer die Aktion – alle darunter verstärken sie.

Startverstärkung

Jedes Königreich-Tableau hat pro Slot ein aufgedrucktes Symbol. Dieses zählt immer als unterste Verstärkung – es kann nie abgeworfen werden.

Tokens auf Krisen

Wenn ein Spieler Symbole auf eine Krise legt, nimmt er die entsprechenden Token und legt sie auf die Krisenkarte. Symbole verschiedener Spieler und Runden addieren sich. Sind genug Token versammelt wird die Krise gelöst – alle Token kommen zurück in den Vorrat.

Kooperationsmoment

Einmal pro Runde darf ein Spieler genau eine Karte an einen Mitspieler weitergeben. Die Karte kommt von der obersten Position eines Slots und wird vom Empfänger sofort auf einen seiner Slots gelegt – oben oder unten, endgültig.

Aufbau

  1. Tableau in die Mitte legen. Fixe Regionskrisen auf die jeweiligen Regionen legen. Granada bekommt zwei Karten gestapelt – Nasridensultanat oben, Belagerung darunter.
  2. Krisenstapel mischen und verdeckt bereit legen.
  3. Kartendeck mischen. Jeder Spieler zieht Karten gemäß Spielerzahltabelle und verteilt sie frei auf seine 3 Slots – mindestens 1 Karte pro Slot. Einmal gelegte Karten können nicht mehr verschoben werden.
  4. Kantabrien ist offen – keine fixe Krise, Slots sofort nutzbar.

Spielablauf

1. Krisenphase

Eine neue Krisenkarte wird aufgedeckt. Ein W6 bestimmt die Zielregion (1–5 = Region von Nord nach Süd, 6 = Krise wird ignoriert und abgelegt).

  • Ist die gewürfelte Region noch muslimisch oder hat bereits eine Krise → eine Region weiter nach Süden.
  • Sind alle eroberten Regionen belegt → die südlichste Krise eskaliert statt einer neuen.
  • Ist der Krisenstapel leer → neu mischen und weiter ziehen.

2. Beratungsphase

Die Spieler schauen gemeinsam das Tableau an. Symbole auf den eigenen Karten dürfen angesagt werden – die Karten selbst darf man nicht zeigen.

3. Aktionsphase

Reihum spielt jeder Spieler die oberste Karte eines seiner Slots. Die Stärke ergibt sich aus der Summe aller passenden Symbole im Stapel plus Fixbonus. Der Spieler entscheidet wohin die Symbole als Tokens gehen – auf eine dynamische Krise oder eine fixe Regionskrise.

4. Kooperationsmoment

Einmal pro Runde darf ein Spieler eine Karte an einen Mitspieler weitergeben.

5. Auflösungsphase

Wurden genug Tokens auf eine Krise gelegt? Krise wird gelöst, Tokens zurück in den Vorrat. Bei einer fixen Regionskrise gilt die Region als erobert. Wurden nicht genug Tokens gelegt? Eskalationsmarker auf die Krise legen. Bei zwei Markern fällt die Region zurück.

6. Nachziehphase

Jeder Spieler zieht Karten nach (gemäß Spielerzahltabelle) und legt sie sofort auf seine Slots – oben oder unten, endgültig. Ist das Deck leer, entfällt das Nachziehen.

Regionen verlieren

Wenn eine dynamische Krise in einer eroberten Region zweimal eskaliert ohne gelöst zu werden:

  • Die Region fällt zurück – die ursprüngliche fixe Regionskrise wird wieder aufgelegt.
  • Alle Slots der Region werden blockiert.
  • Alle angesammelten Tokens auf der Krise gehen verloren.
  • Die Region muss erneut erobert werden.

Krisen

Dynamische Krisen

Jede Krisenkarte zeigt: Symbole zum Lösen (immer mind. 2 verschiedene, Tokens dürfen sich über Runden ansammeln), Soforteffekt beim Aufdecken, Eskalationseffekt wenn ungelöst.

Fixe Regionskrisen

Liegen fest auf muslimischen Regionen. Blockieren alle Slots. Eskalieren nicht. Müssen gelöst werden um die Region zu erobern. Werden schwerer von Nord nach Süd.
